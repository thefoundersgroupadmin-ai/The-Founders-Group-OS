# Pipeline SDR

AI SDR in [[pillar-sales]]. Every weekday at 08:15 it reads every open lead in both offers (Sales System Build and Fractional Sales + AI SDR) and builds the follow-up queue: leads nobody has touched for three or more days, hottest first.

It never sends anything. [[person-ilya]] and [[person-nader]] write and send every follow-up. Its rule is printed in every run so anyone can check it. See [[sop-tfg-pipeline-sdr]].
